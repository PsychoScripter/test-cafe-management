# آزمون عملی پایتون مقدماتی و Git
## پروژه مدیریت سفارش کافه (Cafe Management)

**مدت آزمون:** ۴۵ تا ۶۰ دقیقه

**هدف:** بررسی توانایی خواندن کد، پیدا کردن خطا، Debug کردن و کار با Git.

### سناریو

شما به‌عنوان برنامه‌نویس به یک پروژه مدیریت سفارش کافه ملحق شده‌اید. پروژه توسط برنامه‌نویس قبلی نوشته شده اما تعدادی مشکل دارد.

وظیفه شما این است که:

1. تمام خطاهای پروژه را پیدا کنید.
2. خطاهای Syntax، Runtime و Logic را برطرف کنید.
3. مطمئن شوید ثبت سفارش با اطلاعات معتبر انجام می‌شود.
4. محاسبه مبلغ سفارش و گزارش فروش درست باشد.
5. عملکرد تمام قسمت‌های برنامه را تست کنید.
6. تغییرات را با Git مدیریت کنید.

### قوانین آزمون

- کدها را از ابتدا بازنویسی نکنید.
- تا جای ممکن ساختار فعلی پروژه را حفظ کنید.
- برای هر تغییر یک Commit مناسب ثبت کنید.
- اگر قسمتی از کد را اصلاح کردید، دلیل اصلاح را توضیح دهید.
- در پایان پروژه باید بدون خطا اجرا شود.

### خروجی مورد انتظار

- پروژه بدون خطا اجرا شود.
- سفارش معتبر ثبت شود.
- سفارش نامعتبر پذیرفته نشود.
- مبلغ سفارش درست محاسبه شود.
- گزارش فروش درست باشد.
- قابلیت نمایش و حذف سفارش‌ها درست کار کند.

### بخش Git

۱. پروژه را دریافت کنید.

۲. یک Branch با نام `bug-fixes` بسازید.

۳. باگ‌ها را اصلاح کنید.

۴. تغییرات را با Commitهای معنادار ثبت کنید.

۵. در پایان Branch را با Branch اصلی Merge کنید.

۶. وضعیت نهایی Repository را نشان دهید.
